## Ответы на вопросы
1. **Статическая типизация vs Python.**   
    В Dart тип переменной известен на этапе компиляции и проверяется до запуска, в Python типы определяются в рантайме. Преимущество: целый класс ошибок (например, присвоение строки в `int`) ловится компилятором заранее, а не падением программы.
2. `String?` и `String`.** `String` не может быть `null` — это гарантирует компилятор. `String?` — nullable-тип, может хранить `null`, поэтому перед вызовом методов нужна проверка

3. Зачем `final`.  запрещает повторное присваивание на уровне компилятора, поэтому случайное изменение значения даст ошибку.
4. **Именованный параметр vs позиционный.** Именованный объявляется в `{}` и передаётся по имени, `required` делает его обязательным; порядок не важен. Позиционный передаётся по порядку. Пример: `describePet(name: 'Барсик', age: 3);` против `repeat('xa', 3);`.
